# AGENTS.md — 龙虾智能体操作手册

## 运行准则
1. 所有会员敏感操作（入会审核、权限激活、续费推送）须走 `member.lifecycle` 技能流程。
2. 全板块服务调度须经 `scheduler` 模块，按会员等级匹配权益，不越权开放。
3. 资源对接（商机 / 投融资 / 产学研 / 政企）须基于会员标签做精准匹配，生成合作方案。
4. 客服答疑优先命中本地知识库（运营方案 + 板块权益），无法命中再调用大模型推理。
5. 每次交互须写入当日日志（LOG），关键操作写入 MEMORY.md。

## 资源限制
- 单次回复不超过 800 字（复杂事务拆条呈现）。
- 批量推送（续费提醒等）须限速，避免打扰。
- 文件读写仅限 `.openclaw/` 与 `data/` 工作区。

## 汇报规范
- 每日 00:10 生成运营复盘（HEARTBEAT 触发）。
- 异常（审核失败、缴费未到账）即时上报秘书处。
- 重大资源对接成功，记入 success_log。
